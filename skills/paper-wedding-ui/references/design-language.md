# 设计语言与图纸要求

## 风格总结

纸感复古婚礼请柬，融合编辑式摄影排版与移动端卡片界面。暖米色降低屏幕的冷感，酒红贯穿标题、细线、操作按钮和状态。照片承载情感，留白形成阅读节奏；功能页保持相同视觉，但提高信息密度。

| 元素 | 默认规格 | 使用方式 |
|---|---|---|
| 纸张底色 | #F1E8DF | 大面积背景 |
| 卡片底色 | #FFF8EE | 表单、相册署名、信息卡 |
| 主强调色 | #782D37 | 按钮、编号、英文小标题 |
| 正文色 | #302E29 | 清晰易读，不使用过淡正文 |
| 辅助色 | #827366 | 说明、日期、次级信息 |
| 分隔线 | #DCC5B8 | 1px细线，不使用粗边框 |
| 横向边距 | 24px | 390px画布下；请柬部分加大 |
| 标题 | 25–30px | 细衬线，避免全页粗黑标题 |
| 正文 | 14–16px / 1.7行高 | 可自然换行 |
| 小标题 | 10–12px | 英文大写、适度字距 |
| 手写英文 | Great Vibes，随附OFL | 英文称呼、短句；不用于长段落 |
| 组件圆角 | 12–20px | 卡片与输入区域 |
| 主按钮 | 胶囊形，最小48px高 | 酒红底、浅色文字、柔阴影 |

## 四类页面节奏

- 请柬：邀请标题 → 新人称呼 → 留白 → 故事与竖图 → 日期 → 细节小图 → 时间轴 → 横图 → 地点入口。不要把所有照片都做成满屏背景。
- 赴约：一句迎宾文案 → 填写状态 → 场地、住宿、交通等列表 → 温馨提示 → 接送登记。装饰让位于可读性。
- 相册：横向头图 → 标题 → 分类 → 上传操作 → 双列照片与署名。以示例内容表达有照片/空状态。
- 我的：专属编号卡 → 接送状态 → 署名输入 → 照片入口 → 分享入口。编号卡默认使用程序绘制的通用边框，不包含原作者姓名插画。

## 布局原则

使用正常文档流自适应内容，不锁死页面总高度。图片通过容器比例与 object-position 控制取景。默认导航置于长图末尾，只出现一次，避免长截图中间遮挡内容。最长标题、姓名、地址都需检查。

图纸的复用对象是视觉语言、组件和信息结构，不是原作者的身份、照片内容或实际活动安排。配色和模块可按用户要求变化，但同一套图纸保持一致。

## 二级页面的版式

主页面之外，每个 `↗` 入口和按钮都应打开一个二级页面，二级页面与主页面保持同一视觉。

- **详情页**：返回条 → 英文小标题 → 标题 → 说明 → 头图（照片，或没有照片时用 `art`）→ 若干 `panel` 卡片，每张卡片带 1–3 个次要操作按钮（打开地图、复制地址、拨打电话）→ 提示条 → 联系入口。顶部不堆叠装饰。
- **表单页（回执、到达登记）**：标题与一句宽慰的话 → 字段（下拉字段带箭头，日期与时间并排）→ 酒红提交按钮 → 隐私或用途说明。不要把所有字段做成必填的视觉强调。
- **拍立得与相册页**：来源按钮并排 → 相框预览 → 署名卡 → 一句话输入 → 提交；成功态用横版相框加“保存/去相册”两个按钮。合照页只保留双列照片和“保存原图”，不加筛选条。
- **游戏页**：居中的心形大按钮、一行提示和分数，其余保持安静；说明这是演示。
- **开屏与登录页**：不显示底部导航（`nav:false`）。开屏用满屏照片和两行姓名；登录页分“登录”和“暗号验证”两步，文案克制，只说明为什么需要登录。
- 二级页面通过 `parent` 让对应的底部标签保持高亮，让人知道自己在哪一块。
